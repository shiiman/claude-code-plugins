# サブエージェント作成ガイド

## 概要

サブエージェントは特定のタスクに特化したエージェント定義です。

## 配置場所

```text
plugins/{plugin-name}/agents/{subagent-name}.md
```

## ファイル形式

```markdown
# サブエージェント名

説明文。

## 役割

このサブエージェントの役割と責任。

## 手順

1. ステップ1
2. ステップ2
3. ステップ3

## 出力形式

期待される出力の形式や例。
```

## 命名規則

- 小文字とハイフンを使用: `code-reviewer.md`
- 役割を明確に表す名前にする

## 例

ファイル: `plugins/common/agents/code-reviewer.md`

```markdown
# Code Reviewer

コードの品質をレビューします。

## 役割

- コード品質のチェック
- セキュリティ問題の検出
- パフォーマンス改善の提案

## 手順

1. 対象ファイルを読み込む
2. コーディング規約をチェック
3. セキュリティ脆弱性をスキャン
4. 改善提案をまとめる

## 出力形式

- 問題点: 箇条書きで列挙
- 改善案: 具体的なコード例を含む
```
