# shiiman-go プラグイン

Go 言語開発を支援するプラグインです。

## 概要

Go 言語のベストプラクティスに基づいた開発支援を提供します。

## 対象技術

- Go 言語
- golangci-lint
- govulncheck

## 提供機能

### Skills

| スキル        | トリガー例                              | 説明                                                   |
| ------------- | --------------------------------------- | ------------------------------------------------------ |
| go-check      | 「Go チェック」「go check」「品質確認」 | テスト・lint・脆弱性・ベンチマーク・レビューを並列実行 |
| go-mod-update | 「依存関係を更新」「モジュール更新」    | モジュールバージョン更新（危険度評価付き）             |

## インストール

```bash
claude plugin install shiiman-go@shiiman-claude-code-plugins
```

## 使用方法

```bash
# 品質総合チェック（5項目を並列実行）
「Go チェック」

# モジュールバージョン更新（危険度評価付き）
「モジュール更新」
```

## 特化機能

- テスト・lint・脆弱性・ベンチマーク・コードレビューの一括実行
- Task サブエージェントによる並列チェック
- 統合レポート出力（優先度付き改善提案）
- 依存関係の危険度評価付き更新

## カスタマイズ

このプラグインは拡張可能です。詳細は [プラグイン作成ガイド](../../docs/plugin.md) を参照してください。
