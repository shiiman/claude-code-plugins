# Mod Manager

Go モジュールを管理するスキル。

## トリガー

- 「依存関係を更新」「go mod」「モジュール更新」
- 「依存関係確認」「go.mod 更新」「パッケージ更新」「依存関係を整理」

## 実行内容

`/shiiman-go:mod-update` コマンドを実行します。

## Claude への指示

### 実行手順

1. **コマンド実行**

   `/shiiman-go:mod-update` コマンドの内容に従って実行:

   - 現在の依存関係確認
   - 更新可能なモジュールの分析
   - 危険度評価（🟢/🟡/🔴）
   - 更新実行
   - 結果レポート

2. **出力形式**

   mod-update.md の「結果レポート」形式に従う

### 注意事項

- メジャーバージョンアップは慎重に
- 更新後は必ずビルドとテストを実行
- 脆弱性スキャン（govulncheck）も実施
