# Go Mod Update

Go モジュールのバージョンを更新します。危険度評価付きで安全な段階的更新をサポート。
更新後は check と同じ品質チェック（テスト・静的解析・脆弱性スキャン・ベンチマーク・コードレビュー）を並列実行します。

## Help

`$ARGUMENTS` に `--help` が含まれる場合、以下を表示して終了:

```text
/shiiman-go:mod-update - Go モジュール更新

概要:
  Go モジュールのバージョンを更新する。
  危険度評価付きで安全な段階的更新をサポート。
  更新後は check で品質チェックを自動実行。

使用方法:
  /shiiman-go:mod-update

オプション:
  --help  このヘルプを表示

実行モードの伝え方（フラグの代わり）:
  「確認だけ」「更新可能なものを見せて」  → 更新せず一覧と危険度評価のみ表示
  指定なし                               → 更新を実行

例:
  /shiiman-go:mod-update          # モジュールを更新
  「更新できるモジュールを確認して」  # 更新せず一覧のみ表示
```

## 起動時の自動判断（フラグの代わり）

引数・発話から実行モードを判定する。明示がなければ「更新」とする。

| モード | 条件                                       | 動作                                           |
| ------ | ------------------------------------------ | ---------------------------------------------- |
| 確認   | 「確認だけ」「一覧」「見せて」等の発話あり | 更新可能なモジュールと危険度評価のみ表示し終了 |
| 更新   | 既定                                       | 危険度評価後に更新を実行し、check を呼び出す   |

## ワークフロー

### 1. 現在の依存関係を確認

```bash
cat go.mod
go list -m -u all
```

### 2. 更新可能なモジュールを分析

各モジュールについて以下を評価:

| 危険度  | 基準                                 | 説明                         |
| ------- | ------------------------------------ | ---------------------------- |
| 🟢 安全 | パッチバージョン (v1.2.3 → v1.2.4)   | バグ修正のみ、後方互換性保証 |
| 🟡 注意 | マイナーバージョン (v1.2.0 → v1.3.0) | 新機能追加、非推奨警告あり   |
| 🔴 危険 | メジャーバージョン (v1.x.y → v2.0.0) | 破壊的変更、API の変更       |

### 3. 更新実行

```bash
# バックアップ作成
cp go.mod go.mod.backup
cp go.sum go.sum.backup

# 特定モジュールの更新
go get -u github.com/xxx/yyy@latest

# すべての依存関係を更新
go get -u ./...

# go.mod の整理
go mod tidy
```

### 4. 更新結果レポート

```
✅ 依存関係更新完了

更新されたモジュール:
- github.com/xxx/yyy: v1.2.0 → v1.3.0 (🟡 マイナー)
- github.com/aaa/bbb: v2.1.0 → v2.1.1 (🟢 パッチ)

更新をスキップ:
- github.com/ccc/ddd: v1.0.0 → v2.0.0 (🔴 メジャー - 手動確認推奨)
```

### 5. 品質チェック（check スキル呼び出し）

更新完了後、Skill ツールで `shiiman-go:check` を呼び出す。
check がテスト・静的解析・脆弱性スキャン・ベンチマーク・コードレビューを並列実行する。

## 重要な注意事項

- ✅ メジャーバージョンアップは慎重に
- ✅ 依存関係更新は独立したコミットに
- ✅ CHANGELOG を確認
- ✅ 更新後は Skill ツールで check を呼び出す
- ✅ 確認モード（「確認だけ」）の場合は更新と check をスキップする
