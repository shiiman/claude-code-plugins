# Builder

Go プロジェクトをビルドするスキル。

## トリガー

- 「ビルドして」「go build」「コンパイル」
- 「バイナリ作成」「クロスコンパイル」「Linux 向けビルド」「ビルド実行」

## 実行内容

`/shiiman-go:build` コマンドを実行します。

## Claude への指示

### 実行手順

1. **コマンド実行**

   `/shiiman-go:build` コマンドの内容に従って実行:

   - タスクランナー検出（Taskfile.yml, Makefile）
   - ビルド実行
   - クロスコンパイル（指定時）
   - 結果レポート

2. **出力形式**

   build.md の「結果レポート」形式に従う

### 注意事項

- プロジェクトの既存設定を優先
- クロスコンパイル時は GOOS/GOARCH を明示
- 再現可能ビルドには -trimpath を使用
