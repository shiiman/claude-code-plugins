# Lint

Go プロジェクトの静的解析を実行し、検出された問題を自動修正してコード品質を向上させます。

## 使い方

```bash
/shiiman-go:lint
/shiiman-go:lint --no-fix
/shiiman-go:lint --help
```

## オプション

| オプション | 説明 |
|------------|------|
| `--no-fix` | 自動修正を無効化（検出のみ） |
| `--help` | このコマンドのヘルプを表示 |

## Claude への指示

**`--help` が指定された場合**: このファイルの内容を要約して表示し、終了。

### 実行優先順位

1. **プロジェクトのタスクランナー設定**（最優先）
   - `Taskfile.yml` - lint タスクを自動検出
   - `Makefile` - lint ターゲットを自動検出

2. **設定ファイルベースの実行**
   - `.golangci.yml` が存在する場合は `golangci-lint run`

3. **一般的な静的解析ツール**
   - `golangci-lint` - 複数のリンターを統合実行（推奨）
   - `go vet` - Go 標準の静的解析ツール

### 実行手順

#### 1. タスクランナー検出

```bash
ls -la Taskfile.yml Makefile .golangci.yml 2>/dev/null
```

**検出されるタスク名の例**:
- `lint`, `check`, `lint-go`, `go-lint`
- `analyze`, `static-check`, `vet`

#### 2. 静的解析の実行

```bash
# タスクランナーがある場合
task lint
make lint

# タスクランナーがない場合（自動修正あり）
golangci-lint run --fix ./...

# 自動修正なし
golangci-lint run ./...
go vet ./...
```

#### 3. 結果レポート

```
✅ 静的解析完了

使用したツール: golangci-lint

検出された問題: {N} 件
自動修正された問題: {M} 件
手動修正が必要な問題: {K} 件

自動修正内容:
- {ファイル:行} {修正内容}

手動修正が必要な問題:
- {ファイル:行} {問題の説明}
  推奨: {修正方法}
```

### 主要な静的解析ツール

| ツール | 説明 |
|--------|------|
| golangci-lint | 複数のリンターを統合実行（推奨） |
| go vet | Go 標準の静的解析ツール |
| revive | 高速でカスタマイズ可能なリンター |
| staticcheck | 高度な静的解析 |

### チェック項目の例

- **コードスタイル違反**: フォーマット、命名規則
- **潜在的なバグ**: nil ポインタ参照、未使用変数、型変換エラー
- **パフォーマンス問題**: 不要なアロケーション、非効率なループ
- **セキュリティ問題**: SQL インジェクション、安全でない乱数生成
- **保守性**: 複雑度が高い関数、重複コード

### 注意事項

- **自動修正前にコミット**: 自動修正を実行する前に、未コミットの変更をコミットまたはスタッシュすることを推奨
- **タスクランナー優先**: プロジェクトにタスクランナー設定が存在する場合、それらを最優先で実行
- **段階的な修正**: 初回実行時は多くの警告が出る可能性があるため、段階的に修正することを推奨
