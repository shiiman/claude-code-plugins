# Uninstall

指定したプラグインをアンインストールします。

## 使い方

```bash
/shiiman-plugin:uninstall [plugin-name]
/shiiman-plugin:uninstall --help
```

## オプション

| オプション | 説明                       |
|------------|----------------------------|
| `--help`   | このコマンドのヘルプを表示 |

## Claude への指示

**`--help` が指定された場合**: このファイルの内容を要約して表示し、終了。

### 実行手順

1. プラグイン名が指定されていない場合、インストール済みのプラグイン一覧を表示し、選択を促す
2. 指定されたプラグインがインストールされているか確認
3. 以下のコマンドを実行してアンインストール:

```bash
claude plugin uninstall [plugin-name]
```

4. アンインストール結果を表示

### 出力フォーマット

```
## プラグインのアンインストール

プラグイン `shiiman-xxx` をアンインストールしています...

✅ アンインストール完了
```

### 重要な注意事項

- ✅ `claude plugin uninstall` コマンドを使用
- ✅ アンインストール前にインストール状態を確認
- ✅ アンインストール結果をユーザーに報告
- ❌ インストールされていないプラグインを指定された場合はエラーメッセージを表示
