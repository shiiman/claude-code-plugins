# Plugin Disable

有効なプラグインを無効化します。

## 引数

- `$ARGUMENTS`: プラグイン名（省略時は一覧から選択）

## オプション

| オプション | 説明                     |
|------------|--------------------------|
| `--help`   | このスキルのヘルプを表示 |

## Claude への指示

**`--help` が指定された場合**: このファイルの内容を要約して表示し、終了。

### 実行手順

1. プラグイン名が指定されていない場合:
   - 有効なプラグインの一覧を表示
   - 無効化するプラグインの選択を促す

2. プラグインのインストール状態を確認:
   - インストールされていない場合はエラーメッセージを表示して終了
   - 既に無効な場合はその旨を通知して終了

3. 以下のコマンドを実行して無効化:

```bash
claude plugin disable [plugin-name]
```

4. 無効化結果を表示

### 出力フォーマット

```
## プラグインの無効化

プラグイン `shiiman-xxx` を無効化しています...

✅ 無効化完了

プラグイン `shiiman-xxx` が無効になりました。
```

### 重要な注意事項

- ✅ `claude plugin disable` コマンドを使用
- ✅ 無効化前にプラグインのインストール状態を確認
- ✅ 無効化結果をユーザーに報告
- ❌ インストールされていないプラグインを指定された場合はエラーメッセージを表示
- ❌ 既に無効なプラグインを指定された場合はその旨を通知
