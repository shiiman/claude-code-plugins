# Plugin Show

指定したプラグインの詳細情報を表示します。

## 引数

- `$ARGUMENTS`: プラグイン名（省略時は一覧から選択）

## オプション

| オプション | 説明                     |
|------------|--------------------------|
| `--help`   | このスキルのヘルプを表示 |

## Claude への指示

**`--help` が指定された場合**: このファイルの内容を要約して表示し、終了。

### 実行手順

1. プラグイン名が指定されていない場合、`/shiiman-plugin:list` を実行して一覧を表示し、選択を促す
2. 指定されたプラグインの情報を収集:
   - `.claude-plugin/marketplace.json` から最新バージョンを取得
   - `plugins/{plugin-name}/.claude-plugin/plugin.json` から現在バージョンを取得
   - `plugins/{plugin-name}/skills/` 配下のスキル一覧を取得
   - `plugins/{plugin-name}/agents/` 配下のエージェント一覧を取得
   - `plugins/{plugin-name}/hooks/` 配下のフック一覧を取得
   - `plugins/{plugin-name}/README.md` の内容を取得

3. 詳細情報を整形して表示

### 出力フォーマット

```
## shiiman-xxx プラグイン

### 基本情報

| 項目           | 内容                 |
|----------------|----------------------|
| 名前           | shiiman-xxx          |
| 説明           | プラグインの説明     |
| 最新バージョン | 1.0.0                |
| 現在バージョン | 1.0.0                |
| 状態           | ✅ インストール済み  |

### スキル

| スキル | 説明           |
|--------|----------------|
| skill1 | スキル1の説明  |

### エージェント

（なし）

### フック

（なし）

### README

（README.md の内容を表示）
```

### 重要な注意事項

- ✅ marketplace.json から最新バージョンを取得
- ✅ 各ディレクトリを走査してスキル/エージェント/フックを列挙
- ✅ README.md が存在する場合は内容を表示
- ❌ 存在しないプラグインを指定された場合はエラーメッセージを表示
