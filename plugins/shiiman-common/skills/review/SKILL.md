# Review

ローカル変更を Claude + Codex + セキュリティの 3 観点で並列レビューし、統合結果を表示します。

## Help

`$ARGUMENTS` に `--help` が含まれる場合、以下を表示して終了:

```text
/shiiman-common:review - 統合レビュー

概要:
  ローカル変更を 3 つの観点（コード品質・セキュリティ・Codex）で
  並列レビューし、統合結果を表示します。

使用方法:
  /shiiman-common:review [オプション]

オプション:
  --help    このヘルプを表示

例:
  /shiiman-common:review              # ローカル変更をレビュー
```

## ワークフロー

### 1. 変更差分の取得

Bash ツールで以下を**並列実行**して変更差分を取得:

- `git diff` — ステージされていない変更
- `git diff --cached` — ステージ済み変更

両方とも空の場合は以下を表示して**終了**:

```
レビュー対象の変更がありません。
変更をステージするか、ファイルを編集してから再実行してください。
```

### 2. 3 エージェント並列レビュー

Task ツールで以下の 3 エージェントを**並列起動**する。
各エージェントには取得した diff の全文をプロンプトに含める。

#### 2-1. Claude 品質レビュー（subagent_type: general-purpose）

プロンプト:

```
以下の diff をコードレビューしてください。

観点:
- コード品質（命名・構造・重複）
- 設計（責務分離・凝集度・結合度）
- テスト（テスト漏れ・エッジケース）
- 可読性（コメント・フォーマット・複雑度）

diff:
{diff全文}

結果はマークダウンで、指摘ごとに「ファイル:行番号」を含めてください。
指摘がない場合は「指摘なし」と出力してください。
```

#### 2-2. セキュリティレビュー（subagent_type: general-purpose）

プロンプト:

```
以下の diff をセキュリティ観点でレビューしてください。

チェック項目（OWASP Top 10 基準）:
- インジェクション（SQL / コマンド / XSS）
- 認証・認可の不備
- 機密データの露出（ハードコードされた秘密情報、ログ出力）
- セキュリティ設定ミス
- 既知の脆弱性を持つコンポーネントの使用
- 入力バリデーション不足

diff:
{diff全文}

結果はマークダウンで、脆弱性ごとに「リスクレベル（高/中/低）」と「ファイル:行番号」を含めてください。
指摘がない場合は「指摘なし」と出力してください。
```

#### 2-3. Codex レビュー（subagent_type: Bash）

プロンプト:

```
以下のコマンドを実行し、出力をそのまま返してください:

codex review --uncommitted

コマンドが見つからない場合は「codex コマンドが見つかりません。npm install -g @openai/codex でインストールしてください。」と返してください。
```

### 3. 統合レポート出力

3 エージェントの結果を以下のフォーマットで統合して出力:

```markdown
## 統合レビュー結果

### 1. コード品質レビュー (Claude)

{品質評価・設計指摘・テスト提案}

### 2. セキュリティレビュー

{OWASP チェック結果・脆弱性指摘}

### 3. Codex レビュー

{codex review の出力}

### サマリー

- 重要指摘: {count} 件
- 改善提案: {count} 件
- 総合判定: {OK / 要修正}
```

**カウントルール**:

- 重要指摘: セキュリティリスク「高」 + コード品質の重大な問題
- 改善提案: それ以外の指摘すべて
- 総合判定: 重要指摘が 0 件なら「OK」、1 件以上なら「要修正」

### 4. ユーザー確認

AskUserQuestion ツールで次の選択肢を提示:

- **修正する** — すべての指摘を修正
- **一部修正** — 修正する指摘を選択
- **そのまま** — 修正せず終了

### 5. 修正適用

ユーザーが「修正する」または「一部修正」を選択した場合:

1. 対象ファイルを Read ツールで読み込み
2. Edit ツールで指摘箇所を修正
3. 修正結果をユーザーに報告

## 重要な注意事項

- ✅ 3 エージェントは必ず並列起動する（Task ツールの並列呼び出し）
- ✅ diff が空の場合は早期終了する
- ✅ codex コマンドが未インストールでもエラーにしない
- ❌ diff なしでレビューを実行しない
- ❌ ユーザー確認なしに修正を適用しない
